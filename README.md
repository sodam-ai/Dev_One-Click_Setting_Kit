## 1. 이게 뭔가요?

“바이브코딩”은 **AI에게 한국어로 말하듯 요청해서 프로그램을 만드는 방식**입니다.
그런데 AI 코딩을 하려면 먼저 PC에 여러 **개발 도구**(Git, Python, Node.js 등)를 깔아야 합니다.
하나씩 찾아 설치하면 처음엔 30분~1시간이 걸리고 실수도 잦습니다.

이 키트는 **`dev-one-click-setting-kit.bat` 파일 하나**만 실행하면:

- 필요한 도구를 **자동으로 찾아 설치**하고,
- 이미 있는 도구는 **건너뛰거나 최신으로 올려**주고,
- 설치가 끝나면 **결과 요약 파일**을 만들어 줍니다.
- **스마트폰(안드로이드) 앱을 만들 환경**도 메뉴 **[M]** 하나로 설치합니다(Flutter · Android Studio · adb).

> ⚠️ **Windows 전용**입니다. macOS·Linux에서는 작동하지 않습니다.

**용어 풀이 (처음이면 이것만 알면 됩니다)**

| 용어 | 아주 쉽게 |
|------|----------|
| 터미널 / 콘솔 | 명령을 글자로 입력하는 검은 화면 |
| winget | Windows에 기본 내장된 “프로그램 자동 설치기” |
| CLI | 마우스 대신 글자 명령으로 쓰는 프로그램 |
| LTS | “오래 지원되는 안정 버전”(장기 안전판) |
| PATH | 터미널이 프로그램을 찾는 위치 목록. 설치 직후 **새 터미널**을 열어야 반영됩니다 |
| Flutter | 구글이 만든 **앱 제작 도구**. 한 번 만들면 안드로이드 등에서 실행됩니다 |
| Android Studio | 안드로이드 앱을 만들고 시험하는 **공식 프로그램** |
| adb | PC와 안드로이드 폰을 USB로 이어 주는 **연결 도구** |
| 에뮬레이터 | PC 안에서 돌아가는 **가짜 스마트폰** |
| 가상화 | 에뮬레이터를 빠르게 돌리는 PC 기능(컴퓨터 설정[BIOS]에서 켭니다). **실제 폰을 쓰면 필요 없습니다** |

## 2. 사전 준비물

| 항목 | 필요 조건 |
|------|-----------|
| 운영체제 | **Windows 10 (21H2, 빌드 19044 이상)** 또는 **Windows 11** |
| 인터넷 | **필수** (winget이 인터넷에서 도구를 내려받습니다) |
| 디스크 여유 공간 | 왕초보 3GB / 전체 설치 시 약 7GB 이상 권장 / **모바일 [M] 약 10GB** |
| 권한 | **관리자 권한 불필요**(대부분). 일부 도구만 실패 시 관리자 실행 |
| winget | Windows 10/11에 보통 내장. 없으면 [설치 안내](#17-문제--오류-대처-방법) 참고 |
| PowerShell | Windows에 기본 내장. 키트가 날짜·디스크 확인과 번호 검증에 사용합니다(막혀 있으면 일부 기능이 동작하지 않을 수 있음) |
| 시간 | 왕초보 약 7분 ~ 올인원 약 45분, **모바일 [M] 약 30~40분**(인터넷 속도에 따라 다름) |

> Windows 10 오래된 버전(21H1 이하)은 winget이 불안정합니다. 이 경우 키트가 경고하고 계속 여부를 물어봅니다.

## 3. 필요 프로그램(설치되는 도구 목록)

설치는 **4단계 레벨(누적)**로 나뉩니다. 상위 레벨은 하위 레벨을 모두 포함합니다.

| 레벨 | 누적 개수 | 추가되는 도구 | 예상 시간 |
|------|:--------:|--------------|:--------:|
| **왕초보** | 6 | Git · Python 3 · Node.js LTS · VS Code · Windows Terminal · scoop | ~7분 |
| **중급** | 12 | + Git LFS · GitHub CLI · PowerShell 7 · pnpm · Bun · Ollama | ~15분 |
| **고급** | 17 | + Java 21 LTS · Go · Rust · Flutter+Dart · Stripe CLI | ~35분 |
| **올인원** | 19 | + Ruby · PHP | ~45분 |

**추가로 고를 수 있는 것 ([5] 선택 설치)**

- winget 도구: **uv**(Python 패키지 관리)
- npm 도구(Y/N 선택): Vercel CLI · Supabase CLI · Stripe SDK · Resend SDK · Railway CLI · Clerk · Prisma · Uploadthing

**특정 버전 설치 ([V] 버전 선택 설치)** — 안정/LTS 버전만

- **Python**: 3.11 / 3.12 / 3.13
- **Java(JDK)**: 8 / 11 / 17 / 21 (전부 LTS)
- **Ruby**: 3.2 / 3.3

**scoop — 왕초보 [1]~[4]에 자동 포함 · [S]로 단독 설치**

- **scoop**: 개발용 명령줄 패키지 매니저. winget에 없어 공식 설치 스크립트(`get.scoop.sh`)로 설치합니다. **레벨 [1]~[4] 설치에 자동 포함**(레벨 시작 시 Y 확인 후)되고, [S]로 단독 설치도 됩니다. 보안 상세는 [§13](#13-보안--데이터-흐름).

**Flutter — winget에 없어서 공식 저장소(git)로 설치**

- **Flutter+Dart**: winget에 Flutter 패키지가 없어, Flutter 공식 저장소(`github.com/flutter/flutter`)의 **stable**을 git으로 받아 `%USERPROFILE%\develop\flutter`에 설치합니다(Flutter 공식 문서 권장 위치). **Git이 필요**하고(왕초보 레벨에 포함), Flutter 설치에 **Java는 필요 없습니다**. 이미 Flutter가 있으면 건너뛰고, 설치 위치에 폴더가 이미 있으면 **덮어쓰지 않고** 실패로 알려 줍니다. 설치 후 **사용자 PATH에 자동 추가**되어 새 터미널에서 `flutter`를 쓸 수 있습니다. 보안은 [§13](#13-보안--데이터-흐름), 설정 변경은 [§14](#14-환경-변수).
**모바일 앱 개발 — 메인 메뉴 [M] (Flutter + 안드로이드)**

레벨 [1]~[4]와 **섞이지 않는 별도 메뉴**입니다. 기존 레벨의 동작은 그대로입니다.

| 항목 | 설치 방식 | 설명 |
|------|----------|------|
| Git | winget (`Git.Git`) | Flutter를 받는 데 필요. 없으면 자동으로 함께 설치 |
| Flutter+Dart | 공식 저장소(git) | 위 설명 참고 |
| **Android Studio** | winget (`Google.AndroidStudio`) | 안드로이드 SDK·에뮬레이터·Java(내장 JDK)를 갖춘 공식 개발 도구 |
| **adb** (Android 플랫폼 도구) | winget (`Google.PlatformTools`) | 실제 폰을 USB로 연결해 시험할 때 사용 |
| scrcpy (선택) | winget (`Genymobile.scrcpy`) | 폰 화면을 PC에서 보고 조작 |

- **[M] 메뉴**: `[1] 모바일 기본`(Git·Flutter·Android Studio·adb) · `[2] 기본 + scrcpy` · `[3] 골라서 설치` · `[4] 설치 후 할 일 안내`. 같은 도구를 [5] 선택 설치(`28` Android Studio · `29` adb · `30` scrcpy)로도 고를 수 있습니다.
- **설치 전 점검**: 디스크 여유 약 10GB(실측: Flutter 2.56 + Android SDK 4.35 + Android Studio 3.09GB), 가상화 켜짐 여부(에뮬레이터용 — **안내만 하고 설치는 막지 않습니다**. 실제 폰 연결에는 필요 없음).
- **설치 후 안내(자동화하지 않는 단계)**: Android Studio 첫 실행(SDK 내려받기) → `flutter doctor --android-licenses`(라이선스 동의는 **직접**) → `flutter doctor` → 폰 USB 디버깅 켜는 법. 키트는 **환경 변수를 등록하지 않고** 안내만 합니다.
- **[9] 설치 확인**: Android Studio·adb·scrcpy 항목 추가, 그리고 원하면 `flutter doctor` 결과를 요약(정상/경고/오류)해 보여 줍니다(1~2분 걸릴 수 있어 y를 눌렀을 때만 실행).
- **iOS 앱 빌드는 Windows에서 할 수 없습니다**(Mac 필요). 이 키트는 안드로이드 앱 개발 환경까지 준비합니다.

**설치 후 자동으로 되는 것 (Post-install)**

- Git 줄바꿈 설정(`core.autocrlf true`) 자동
- Git 이름·이메일은 **자동 저장하지 않고 안내만** (개인정보 보호)
- Python `pip` 최신화, Node의 광고 메시지 끄기(`npm config set fund false`)
- **Claude Code CLI 자동 설치** (성공/실패를 정직하게 표시)
- Ollama 로컬 AI 모델은 **안내만**(자동 다운로드 안 함 — 용량 큼)
- 설치된 도구가 잘 인식되는지 **PATH 검증** 출력

> AI 에디터(Cursor, Claude Desktop 등)는 **프로그램**이라 자동 설치하지 않고 **[8] 직접 다운로드**에서 공식 페이지를 열어 줍니다.

## 4. 다운로드 방법

**방법 A — Releases(권장)**
저장소 페이지 오른쪽 **Releases** → 최신 버전 → **Assets**의 `dev-one-click-setting-kit.bat` 클릭해 저장.

**방법 B — ZIP**
`< > Code` 버튼 → **Download ZIP** → 압축 해제 → 폴더 안의 `dev-one-click-setting-kit.bat` 사용.

> 파일 하나(`.bat`)만 있으면 됩니다. 다른 파일은 설명서·개발 기록입니다.
>
> **내 파일이 최신인지 확인하는 법:** `.bat`을 우클릭 → 메모장으로 열면 맨 위 주석에 `DEV-KIT.bat v숫자`가 있습니다. 이 문서의 **[M] 모바일 메뉴**는 **v1.7.0 이상**, **숫자(1/2) 선택 · 번호 검증 · Enter 반복 방지**는 **v1.7.1 이상**에 들어 있습니다. Releases에서 받은 파일의 버전이 이보다 낮으면, **방법 B(ZIP)** 로 `main` 브랜치의 파일을 받으세요.

## 5. 빠른 시작 (3분 요약)

1. `dev-one-click-setting-kit.bat`를 **더블클릭**.
2. 파란 경고창(SmartScreen)이 뜨면 **[추가 정보] → [실행]**.
3. 메뉴가 나오면 처음이면 **`A`**(가장 쉬운 추천 설치) 또는 **`1`**(왕초보) 입력 후 **Enter**. (폰 앱을 만들고 싶다면 **`M`**)
4. “설치 시작?” 질문에는 **`1`**(예)을 입력합니다(기존처럼 `y`도 됩니다). 레벨 설치에서 “이미 설치된 것 처리”를 물으면 그냥 **Enter**(건너뜀).
5. 끝나면 안내대로 **새 터미널**을 열어 사용 시작.

## 6. 실행 방법

1. **파일 받기** → [4. 다운로드](#4-다운로드-방법).
2. **더블클릭 실행.** 관리자 권한은 대부분 불필요. 일부 실패 시 파일 **우클릭 → “관리자 권한으로 실행”**.
3. **SmartScreen 파란 창**이 떠도 정상입니다: **[추가 정보] → [실행]**.
4. 검은 화면(터미널)에 메뉴가 뜹니다. 원하는 번호/문자를 입력하고 **Enter**.
5. 예/아니오 질문은 **`1`=예 / `2`=아니오**로 답합니다. **아무것도 입력하지 않고 Enter만 누르면 실행하지 않습니다**(기본값이 있는 질문은 기본값).

> 인터넷으로 내려받기 때문에 시간이 걸릴 수 있습니다. **창을 닫지 마세요.**

## 7. 사용 방법 (메뉴 설명)

실행하면 나오는 메인 메뉴:

```
[1] 왕초보 설치     처음 시작 (6개,  ~7분)
[2] 중급 설치       (12개, ~15분)
[3] 고급 설치       (17개, ~35분)
[4] 올인원 설치     (19개, ~45분)
[5] 선택 설치       원하는 번호만 골라서
[6] 업데이트        설치된 도구를 안정(LTS) 버전으로
[7] 제거            도구 삭제 (개별/전체)
[8] 직접 다운로드   공식 사이트 URL 목록 (winget 불가 시)
[9] 설치 확인       O/X + 버전 표시
[0] 종료
[A] 가장 쉬운 추천 설치   처음이면 이거! (기본 5종 + AI 안내)
[V] 버전 선택 설치        특정 안정버전 (Python/Java/Ruby)
[S] scoop 설치          개발용 패키지 매니저 (winget 외)
[M] 모바일 앱 개발      Flutter + Android Studio + adb (안드로이드)
```

| 메뉴 | 설명 |
|------|------|
| **[1]~[4]** | 레벨별 일괄 설치. 설치 전 목록·소요시간을 보여주고 **Y/N** 확인 |
| **[A]** | 기본 5종 설치 + Cursor·Claude Desktop 다운로드 페이지 열기 |
| **[5]** | 번호를 쉼표로 입력(예: `1,3,8`). **Enter만 누르면 권장 기본팩(1~5)**. 고른 도구 **이름을 미리 보여준 뒤** 설치 |
| **[V]** | Python/Java/Ruby의 **특정 안정 버전** 선택. 잘 모르면 그냥 Enter(권장값) |
| **[S]** | **scoop**(개발용 패키지 매니저) 설치. winget에 없어 공식 스크립트 사용 — 실행 전 **동의(Y/N)**. 보안 상세 [§13](#13-보안--데이터-흐름) |

adb version

## 12. 아키텍처

- **단일 파일**: 순수 Windows 배치 스크립트(`.bat`) 1개. 별도 설치/빌드 없음.
- **패키지 관리**: **winget**(Microsoft 운영 공식 저장소) 사용. 각 도구는 공식 소스에서 설치하며, winget이 **내려받은 설치 파일의 해시(지문)를 저장소 정보와 대조**합니다.
- **구조(서브루틴)**: 메뉴 → `:PRE_CHECK`(사전 점검) → `:INSTALL`/`:NPM_INSTALL`(설치·재시도) → `:POST_*`(설치 후 설정) → `:MAKE_REPORTS`(리포트) → `:PATH_CHECK`(검증).
- **예외 설치 경로 2건**: winget에 없는 **scoop**(공식 설치 스크립트)과 **Flutter**(공식 저장소 git). 전용 서브루틴(`:INSTALL_SCOOP`, `:INSTALL_FLUTTER`)으로 분리되어 있고, 실패 시 정직하게 `[실패]`를 표시합니다.
- **모바일 메뉴**: `:DO_MOBILE`(선택) → 사전 점검 → `:INSTALL_MOBILE` → `:POST_MOBILE`(안내). 레벨 [1]~[4]와 **섞이지 않는 별도 흐름**입니다.
- **입력 처리**: 모든 입력 칸은 질문 직전에 값을 비워 **Enter만 누르면 이전 선택이 반복되지 않고**, [5]·[M]-3·[7]의 번호는 **검증 후** 사용합니다(특수문자·범위 밖 번호 거부).
- **이식성**: `%~dp0` 기반이라 파일 위치·이름을 바꿔도 작동.
- **인코딩**: CP949(한국어 Windows 기준). 영어 Windows에서는 메뉴 글자가 깨질 수 있음(알려진 제약 — [14 참고](#17-문제--오류-대처-방법)).

## 13. 보안 / 데이터 흐름

- **관리자 권한 불필요**(사용자 범위 설치). 기업/학교 PC 대응.
- **공식 소스만(winget)**: winget 설치는 전부 `--source winget`(Microsoft 운영 공식 저장소). winget은 설치 파일의 **해시를 저장소 정보와 대조**합니다(각 설치 프로그램의 개발사 서명 검증 여부는 도구마다 다릅니다).
- **원격 스크립트 예외 — scoop 1건**: scoop은 winget에 없어 공식 설치 스크립트(`https://get.scoop.sh`, HTTPS)를 실행합니다. **설치 스크립트를 받아 바로 실행하는 유일한 경로**이며, **레벨 [1]~[4] 설치(시작 시 Y 확인) 또는 [S] 선택** 시에만 실행됩니다(winget과 달리 서명 검증은 없고, 공식 출처만 사용).
- **Flutter 예외 — git 저장소 1건**: Flutter는 winget에 없어 공식 저장소(`https://github.com/flutter/flutter.git`, HTTPS, stable)를 git으로 내려받습니다. 내려받은 Flutter 도구가 **처음 실행할 때 Dart SDK를 Google 서버에서 받습니다**(서명 검증 없음, 공식 출처만). 설치 위치가 사용자 폴더 안이라 관리자 권한은 필요 없습니다.
- **모바일 도구(Android Studio·adb·scrcpy)는 모두 winget 경유**라 기존 도구와 같은 방식(서명 검증)입니다. Android SDK **라이선스 동의는 사용자가 직접** 합니다(키트가 대신 동의하지 않음).
- **입력 최소화·검증**: 사용자는 **메뉴 번호만** 입력합니다. [5]·[M]의 번호는 숫자·쉼표·범위만 허용하고, 그 외 입력은 거부합니다. 임의 명령 실행 통로 없음.
- **scoop 단계가 바꾸는 것**: scoop을 설치할 때 키트가 **PowerShell 실행 정책(현재 사용자 범위)을 `RemoteSigned`로 설정**하고 공식 스크립트를 실행합니다(scoop이 요구하는 값). 되돌리는 법은 [§14](#14-환경-변수).
- **npm으로 설치되는 것**: Claude Code CLI, 레벨 설치의 Railway CLI, 그리고 Y로 고르거나 [5]에서 고른 npm 도구(Vercel CLI 등)는 **winget이 아니라 npm 레지스트리**에서 받습니다(npm의 패키지 무결성 확인 방식).
- **개인정보 보호**: Git 이름/이메일은 **자동 저장하지 않고 안내만**.
- **키트가 보내는 데이터 없음**: 만들어지는 파일은 **로컬**(리포트/로그)뿐이며 서버로 보내지 않습니다. 키트가 직접 하는 네트워크 동작은 ① 인터넷 연결 확인용 `ping`(8.8.8.8) 1회 ② winget·npm 호출 ③ scoop 공식 스크립트 내려받기(`get.scoop.sh`) ④ Flutter 공식 저장소 받기(`github.com/flutter/flutter`)뿐이며, 전부 위에 적은 공식 출처입니다. 그 밖의 접속(Dart SDK·Android SDK 등)은 설치된 도구 자체가 합니다.
- **설치되는 도구의 자체 통신**: 설치된 도구(예: Flutter·Android Studio·VS Code)는 각자 **사용 통계·업데이트 확인**을 할 수 있습니다. 이는 키트가 아니라 해당 도구의 설정·약관을 따릅니다.
- **리포트 내용**: PC 이름(COMPUTERNAME)·설치 결과만. **사용자명·홈 경로·비밀번호 등 민감정보 미포함.**
- **시크릿 없음**: 코드/문서에 API 키·토큰·비밀번호가 들어있지 않습니다.

## 14. 환경 변수

**따로 설정할 환경 변수는 없습니다.** 파일을 받아 바로 실행하면 됩니다. (`.env` 같은 설정 파일도 쓰지 않습니다.)

**키트가 읽기만 하는 Windows 기본 변수**

| 변수 | 어디에 쓰나 |
|------|------------|
| `%USERPROFILE%` | scoop 설치 위치 확인(`...\scoop\shims\scoop.cmd`), **Flutter 설치 위치**(`...\develop\flutter`) |
| `%ProgramFiles%` | Git·Android Studio 설치 위치 확인(방금 설치돼 PATH에 아직 없을 때) |
| `%SCOOP%` | **이미 scoop을 다른 폴더에 쓰고 있다면** 그 위치를 우선 사용 |
| `%LOCALAPPDATA%` | 첫 실행 안내를 한 번만 띄우기 위한 표시 파일 저장 |
| `%TEMP%` | 임시 작업(`flutter doctor` 요약용 임시 파일은 끝나면 지웁니다) |
| `%COMPUTERNAME%` | 설치 리포트에 PC 이름 기록 |
| `%DATE%` · `%TIME%` | 리포트·로그 파일 이름과 소요 시간 계산 |

**키트가 바꾸는 설정 (전부 되돌릴 수 있음)**

| 무엇 | 값 | 되돌리는 명령 |
|------|----|--------------|
| Git 줄바꿈 | `core.autocrlf=true` | `git config --global --unset core.autocrlf` |
| npm 광고 끄기 | `fund=false` | `npm config delete fund` |
| 콘솔 색상 | 레지스트리 `HKCU\Console\VirtualTerminalLevel=1` | 해당 레지스트리 값 삭제 |
| PowerShell 실행 정책 (scoop 설치 시만) | 현재 사용자 범위 `RemoteSigned` | `Set-ExecutionPolicy Undefined -Scope CurrentUser` (단, scoop이 동작하지 않을 수 있음) |
| 사용자 PATH (Flutter만) | `%USERPROFILE%\develop\flutter\bin` **1개 추가** | [7] 제거에서 Flutter를 제거하면 자동 정리 · 또는 환경 변수 편집에서 그 줄 삭제 |

> **PATH는 대부분 이 키트가 건드리지 않습니다.** 각 설치 프로그램(winget·scoop)이 스스로 등록합니다. **예외는 Flutter 1건**입니다: git으로 받는 Flutter는 PATH를 등록해 주는 설치 프로그램이 없어, 키트가 **사용자 PATH에 위 경로 1개만** 추가합니다(이미 있으면 추가 안 함, 기존 항목은 그대로 보존).
> 그래서 설치 직후 현재 창에서는 명령어가 안 먹히고, **새 터미널**을 열어야 인식됩니다. (PATH 변경을 윈도우에 알리려고 `KIT_PATH_REFRESH`라는 사용자 변수를 **잠깐 만들었다 바로 지웁니다**.)
>
> **Android SDK 관련 환경 변수(`ANDROID_HOME` 등)는 키트가 등록하지 않습니다.** SDK 위치를 못 찾는다고 나오면 [M]-[4] 안내의 `flutter config --android-sdk` 명령을 한 번 실행하세요(Flutter 자체 설정이라 PC 설정은 바뀌지 않습니다).

## 15. 빌드 · 테스트 · 배포 방법

### 빌드 — **없습니다**

`.bat` 파일 하나라서 **컴파일·빌드 과정이 없습니다.** 받은 파일을 그대로 실행하면 끝입니다.
개발 도구나 패키지 매니저(npm 등)를 미리 깔 필요도 없습니다.

### 테스트 — 사용자용 (따라 하기)

1. `dev-one-click-setting-kit.bat` 실행
2. **`[9] 설치 확인`** 선택 → 도구별로 `[O]`/`[X]`와 버전이 표시됨
3. `[O]`인데 명령어가 안 먹히면 → **새 터미널**을 열고 다시 확인
4. 이상하면 같은 폴더의 `install-log-날짜.txt` **마지막 줄** 확인

### 테스트 — 코드를 고친 뒤 (개발자용)

배치 파일은 문법 오류가 **실행 중에만** 드러납니다. 고친 부분은 반드시 실제로 실행해 보세요.

1. 수정한 블록만 별도 `.bat`로 떼어내 `cmd`에서 실행 → 분기·출력 확인
2. 전체 실행 → 메뉴 번호를 하나씩 입력해 오류 문구가 없는지 확인
3. `[9] 설치 확인`으로 기존 기능이 깨지지 않았는지 확인
4. **잘못된 입력도 시험**하세요: 빈 입력(Enter만), 없는 번호, 특수문자(`&` `(` `"` `%`), 아주 긴 입력.

> ⚠️ **내 PC에서 설치 흐름을 그냥 돌려 보지 마세요.** 레벨 설치는 scoop 공식 스크립트를 실행하며 PowerShell 실행 정책을 바꾸고, `[A]`는 브라우저 창을 엽니다. 설치·제거 흐름을 시험할 때는 **가짜 `winget`/`npm`/`scoop` 실행 파일을 PATH 맨 앞에 두고**, `USERPROFILE`·`LOCALAPPDATA`를 임시 폴더로 바꿔 격리하세요. 입력은 한 번에 여러 줄을 밀어 넣지 말고 **질문이 화면에 나온 뒤 한 줄씩** 보내야 정확합니다(배치의 입력 칸은 줄 단위 일괄 입력을 안정적으로 받지 못합니다).

### 배포 — 유지보수자용

1. `CHANGELOG.md`에 변경 내용 추가
2. `.bat` 파일 맨 위 주석의 버전 번호 갱신
3. 변경사항 commit → PR → `main` 병합
4. GitHub **Releases → Draft a new release** → 태그(예: `v1.7.1`) 지정 → **Assets에 `dev-one-click-setting-kit.bat` 첨부**
5. 첨부 직전에 **저장소의 파일과 바이트가 같은지**(CP949·CRLF 유지) 확인

> ⚠️ **`.gitattributes`의 `*.bat -text` 줄을 절대 지우지 마세요.**
> 이 줄이 없으면 GitHub에서 ZIP으로 받을 때 `.bat`의 줄바꿈이 LF로 바뀌어 **실행하자마자 창이 닫힙니다.** (v1.5.1에서 실제로 고친 문제입니다.)

## 16. 운영 주의사항

- **설치 후에는 새 터미널을 여세요.** 기존 창은 설치 전 상태라 명령어를 못 찾습니다.
- **설치 중에는 창을 닫지 마세요.** 내려받는 도중 끊기면 그 도구만 실패합니다(다시 실행하면 이어서 됩니다).
- **여러 번 실행해도 안전합니다.** 이미 설치된 것은 기본값이 “건너뜀”입니다.
- **회사·학교 PC**는 보안 정책으로 winget이 막혀 있을 수 있습니다 → `[8] 직접 다운로드` 이용, 그래도 안 되면 전산 담당자에게 문의하세요(사용자가 풀 수 없는 권한 문제입니다).
- **백신이 `.bat`을 차단**할 수 있습니다. 공식 저장소에서 받은 파일이 맞는지 확인한 뒤 허용 목록에 추가하세요.
- **로그·리포트 파일**은 실행할 때마다 날짜별로 쌓입니다. 필요 없으면 지워도 됩니다(`.gitignore`에 있어 저장소에는 올라가지 않습니다).
- **리포트를 남에게 보낼 때**는 PC 이름이 들어 있다는 점만 알아두세요. 비밀번호·개인 파일 정보는 들어가지 않습니다.
- **Flutter는 `%USERPROFILE%\develop\flutter`에 설치됩니다.** 그 위치에 다른 폴더가 이미 있으면 키트는 덮어쓰지 않고 실패로 알려 줍니다. Flutter 공식 문서는 경로에 **공백·특수문자**가 없는 곳을 권장하며, 처음 실행할 때 Dart SDK(수백 MB)를 내려받느라 몇 분 걸립니다.
- **모바일 환경([M])은 용량이 큽니다.** 디스크 약 10GB, 설치 30~40분이 걸리고, Android Studio **첫 실행 때 SDK를 추가로 내려받습니다**. 안드로이드 에뮬레이터는 PC의 가상화가 켜져 있어야 빠르게 동작하며, 실제 폰을 USB로 연결하면 가상화 없이도 됩니다.
- **scoop은 레벨 설치에서 자동으로 함께 설치**됩니다(시작할 때 보여 주는 목록에 포함). 원치 않으면 [5] 선택 설치를 쓰세요.
- **영어(비한국어) Windows**에서는 메뉴 글자가 깨질 수 있습니다(알려진 제약).

| 증상 | 원인(가능성) | 대처 |
|------|-------------|------|
| 파란 경고창(SmartScreen) | Windows 보호 기능 | **[추가 정보] → [실행]** (정상) |

| 설치 중 창이 갑자기 닫힘 | 오류 발생 | 같은 폴더의 `install-log-날짜.txt` **마지막 줄** 확인 |
| 특정 도구만 설치 실패 | 네트워크·정책·winget 일시 오류 | 자동 1회 재시도됨. 그래도 안 되면 **[8] 직접 다운로드** |

| `flutter doctor`에 Android 경고/오류 | Android Studio 첫 실행 전 · 라이선스 미동의 · SDK 위치 | **[M] → [4]** 안내 순서대로: Android Studio 한 번 실행 → `flutter doctor --android-licenses` → 필요하면 `flutter config --android-sdk` |
| `1부터 30 사이의 숫자만…` 안내가 나옴 | [5]·[M]에 숫자·쉼표 이외를 입력하거나 범위 밖 번호 입력 | 안내대로 `1,3,6`처럼 **숫자와 쉼표만** 입력 |
| `adb server version doesn't match` 메시지 | adb가 두 곳(키트 설치 + Android Studio 내장)에 있어 버전이 다름 | `adb kill-server` 입력 후 다시 시도 |
| 관리자여도 설치 안 됨 | 백신이 `.bat` 차단 | 백신 허용 목록 추가 또는 잠시 실시간 보호 해제 후 재시도 |
| **메뉴 글자가 깨져 보임** | **영어(비한국어) Windows** | 한국어 Windows에서는 정상. 영어 Windows는 알려진 제약(향후 PowerShell 런처로 개선 예정) |
| 디스크 공간 부족 경고 | 여유 공간 미달 | 공간 확보 후 재실행(레벨별 3/4/6/7GB, 모바일 [M]은 약 10GB 기준) |

> 오류 신고 시: 스크린샷 대신 `install-log-날짜.txt`를 첨부하면 원인 파악이 쉽습니다. (민감정보 없음)

## 18. 자주 묻는 질문 (FAQ)

**Q. 코딩을 한 번도 안 해봤는데 써도 되나요?**
네. **[A]** 또는 **[1]**만 눌러도 기본 환경이 갖춰집니다.

**Q. 다시 실행해도 되나요?**
네. 이미 설치된 것은 기본값 **건너뜀**이라 안전합니다.

**Q. 관리자 권한이 꼭 필요한가요?**
대부분 아니요. 일부 도구만 실패할 때 관리자 실행을 안내합니다.

**Q. 특정 버전(예: Python 3.11)을 깔 수 있나요?**
네. **[V] 버전 선택 설치**에서 안정 버전만 고를 수 있습니다.

**Q. 모바일 앱(안드로이드)도 만들 수 있나요?**
네. 메인 메뉴 **[M] 모바일 앱 개발**에서 Flutter·Android Studio·adb를 한 번에 설치하고, 화면의 **설치 후 할 일**을 따라 하세요. iOS 앱은 Windows에서 만들 수 없습니다(Mac 필요).

**Q. 예/아니오는 어떻게 답하나요?**
`1`(예) 또는 `2`(아니오)를 입력하세요. 기존처럼 `y`/`n`도 됩니다. **아무것도 입력하지 않고 Enter만 누르면 실행하지 않습니다.**

**Q. 폰이 없어도 앱을 만들어 볼 수 있나요?**
네. Android Studio의 **가상 폰(에뮬레이터)** 으로 시험할 수 있습니다. 다만 PC의 **가상화**가 켜져 있어야 빠르고, 꺼져 있으면 느리거나 안 될 수 있습니다. 실제 폰을 USB로 연결하면 가상화 없이 됩니다.

**Q. Flutter나 Android Studio가 이미 있는데 [M]을 써도 되나요?**
네. 이미 있는 것은 **건너뜀**으로 처리합니다. 단 Flutter는 키트 위치(`%USERPROFILE%\develop\flutter`)에 **다른 폴더가 이미 있으면 덮어쓰지 않고 실패로 알립니다.**

**Q. 아이폰(iOS) 앱도 만들 수 있나요?**
아니요. iOS 앱 빌드는 **Mac이 필요**해서 Windows에서는 할 수 없습니다. 이 키트는 안드로이드까지 준비합니다.

**Q. 설치한 걸 지우려면?**
**[7] 제거** → 개별 또는 전체.

**Q. 인터넷이 꼭 필요한가요?**
네. winget이 인터넷에서 도구를 내려받습니다.

**Q. macOS/Linux에서 되나요?**
아니요. **Windows 전용**입니다.
